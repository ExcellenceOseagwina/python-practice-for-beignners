# Beginner Python Practice

A collection of small, standalone Python programs for practicing beginner
programming concepts. The examples cover variables, input and output,
conditionals, arithmetic, and loops, with a few cybersecurity-themed exercises.

## Requirements

- Python 3
- No third-party packages

## Running an exercise

Run a script from the project directory:

```bash
python simple_calculator.py
```

Choose another `.py` file to run a different exercise. Interactive scripts
prompt for input in the terminal.

## Exercises

| File | What it covers |
| --- | --- |
| `bool.py` | Boolean values |
| `bill_split_calc.py` | Splitting a bill with a tip |
| `cyber_access_checker.py` | Demo role-based access checks |
| `cyber_profile_gen.py` | Variables, calculations, and formatted output |
| `cybersecurity_risk_classifier.py` | Validating scores and classifying a risk score |
| `electricity_bill_calculator.py` | User input and conditional bill calculations |
| `game_profile.py` | Variables and formatted output |
| `login_access_simulator.py` | Basic conditional login simulation |
| `loops.py` | `for`-loop practice and a `while`-loop counting exercise |
| `movie_rating.py` | Variables and output |
| `personal_profile_generator.py` | Variables and profile output |
| `print_variables.py` | Printing variables and student details |
| `simple_atm_simulator.py` | Menu choices and simulated transactions |
| `simple_calculator.py` | Arithmetic and operator selection |
| `simple_guessing_game.py` | Comparisons and conditionals |
| `simple_student_result_mang_system.py` | Score validation, averages, and grades |
| `student_grade_calculator.py` | Conditional grade classification |
| `worker_details.py` | Variables and formatted profile output |

Many of the `for`-loop examples in `loops.py` are commented practice solutions;
the active `while`-loop example prints the numbers 1 through 20.

## Note

The login and access-checking scripts use hard-coded example credentials and
are for learning conditionals only. They are not secure authentication systems
and should not be used to protect real accounts or data.
