# Contributing

Thank you for taking an interest in improving Python Practice for Beginners!

This repository is intended to remain approachable for people who are learning Python. Contributions should prioritize correctness, clarity, and beginner-friendly explanations.

## Ways to contribute

You can contribute by:

- Fixing a bug or incorrect explanation.
- Improving comments, instructions, or documentation.
- Adding a focused Python exercise.
- Adding a small console-based project.
- Improving an existing exercise while preserving its learning objective.

## Before you begin

1. Check the existing folders and files to avoid duplicating an exercise.
2. Keep changes focused and explain the problem they solve.
3. For substantial changes, open an issue first to discuss the proposed approach.

## Guidelines for Python exercises

- Use Python 3 and prefer the standard library unless a dependency is necessary for the lesson.
- Keep examples small and focused on the concepts the learner is expected to know.
- Use descriptive filenames and consistent naming.
- Prefer clear variable names over clever or overly compressed code.
- Add comments when they clarify a concept; avoid comments that merely repeat the code.
- State any assumptions about user input.
- Include a short exercise or challenge when appropriate.
- Do not include real credentials, API keys, personal information, or other secrets.

## Documentation guidelines

- Use clear Markdown headings and concise explanations.
- Check that links point to existing files.
- Distinguish completed exercises from planned roadmap topics.
- Include run commands from the repository root when relevant.
- Keep instructions suitable for a beginner who may be unfamiliar with terminals or Python tooling.

## Test your changes

Before submitting:

1. Run the modified Python file(s).
2. Try representative inputs, including boundary or invalid inputs where relevant.
3. Check that the README links and command paths are correct.
4. Review your diff to ensure unrelated files were not changed.

## Submit a pull request

1. Fork the repository.
2. Create a branch for your change.
3. Make and test your changes.
4. Commit with a clear message, such as `docs: clarify beginner setup instructions`.
5. Open a pull request describing what changed and why.

Thank you for helping make the repository more useful for learners!
