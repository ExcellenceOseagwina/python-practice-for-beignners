# Loop Exercises

The loop exercises are grouped by loop type and topic. Run a script from the
repository root, for example:

```bash
python loops/while_loops/counting.py
```

## For loops

- `for_loops/number_ranges.py` — counting, number ranges, and multiplication
  tables (Exercises 1–7).
- `for_loops/conditions.py` — divisibility and nested-condition practice
  (Exercises 8–10 and 16–19).
- `for_loops/totals_and_counts.py` — accumulators and counters
  (Exercises 11–15 and 20).

The `for`-loop files contain commented practice solutions; uncomment an
exercise to run it.

## While loops

- `while_loops/counting.py` — counting exercises. The even-number exercise is
  active and prints the even numbers from 2 through 50.
