# Advanced Python Course Roadmap

There are no advanced exercises in this project yet. This folder marks the next
stage after the beginner and intermediate lessons.

Here are some topics to learn next:

1. **Functions** - give a name to steps you want to reuse.
2. **Lists and dictionaries** - keep groups of related information together.
3. **More loops** - work through the items in a list or text.
4. **Handling errors** - respond when someone enters an unexpected answer.
5. **Files and modules** - save information and split a program into files.
6. **Classes** - create your own kinds of values.
7. **Tests** - check that a program gives the results you expect.

When adding lessons, explain the code with simple comments and give students a
small exercise to try.
